# Netflix Landing Page Clone 🎬

A modern, pixel-perfect, responsive Netflix landing / introduction page clone built using **pure HTML and CSS**.

## ✨ Features
- **Cinematic Hero Banner**: Complete with backdrop mosaic, dark radial/linear gradient vignette overlays, and modern floating-label email signup input.
- **Iconic Curved Luminous Arc**: Highlighting the transition between the hero and trending sections.
- **Top 10 Trending Now Shelf**: Showcasing movie posters with the signature Netflix large outlined rank numbers.
- **"More Reasons to Join" Grid**: Modern feature tiles with gradient backgrounds, glassmorphism accents, and SVG iconography.
- **TV & Offline Showcase Splits**: Classic Netflix interactive previews with streaming TV frames and mobile download indicator animations.
- **Pure CSS FAQ Accordion**: Expandable FAQ using native `<details>` and `<summary>` elements with animated `+` to `✕` toggle (no JavaScript required).
- **Responsive & Accessible**: Optimized for mobile, tablet, and desktop viewports, with full print styling for PDF generation.

## 🛠️ How to Run Locally
1. Clone the repository:
   ```bash
   git clone https://github.com/Anika-19-varshney/NETFLIX-DEMO.git
   cd NETFLIX-DEMO
   ```
2. Open `index.html` in any web browser or use VS Code Live Server.

---

## 🌐 Deploy to Vercel
1. Go to [vercel.com/new](https://vercel.com/new).
2. Connect your GitHub account and import the repository `Anika-19-varshney/NETFLIX-DEMO`.
3. Keep default settings (Static site, Root directory: `./`).
4. Click **Deploy**.
